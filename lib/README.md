# simple tokenizer

Runtime artifact: `libsimple.so` (ignored by Git).

Run `deno task setup:simple` to install the Linux x86_64 build of
[wangfenjin/simple v0.7.1](https://github.com/wangfenjin/simple/releases/tag/v0.7.1).
The installer verifies both archive and binary SHA-256 against pinned values.
Upstream source and license: https://github.com/wangfenjin/simple/tree/v0.7.1.
Only `simple_query` is used; external Jieba dictionaries are not required.
